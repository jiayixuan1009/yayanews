# YayaNews 全面 SEO 复审报告

审计日期：2026-06-13  
审计对象：`https://yayanews.cryptooptiontool.com`  
生产版本：`v2026.06.14-seo14`  
审计目标：复查生产站点技术 SEO、页面 SEO、sitemap、News sitemap、索引信号与 GSC 0 展现相关风险。

## 1. 结论

本轮复审结论：生产站点的核心技术 SEO 已经从 2026-06-12 的失败状态恢复到通过状态。当前没有发现会导致全站无法被 Google 抓取或无法进入索引队列的 P0 技术阻断。

生产验证脚本结果：

```bash
npm.cmd run verify:seo -- --base https://yayanews.cryptooptiontool.com --expected-origin https://yayanews.cryptooptiontool.com --sample-article-urls 10 --probe-sitemap-urls 50 --sample-sitemap-kinds authors:3,topics:3,tags:8,guides:3 --fetch-timeout-ms 60000
```

结果：

```txt
SEO metadata check passed: 66/66 checks OK.
```

这意味着核心页面、文章详情页、长尾作者/专题/标签页、sitemap 抽样 URL、canonical、OG URL、robots meta、hreflang、HTML 缓存、结构化数据、robots 与 sitemap 资源均已通过自动化检查。

如果 GSC 当前仍然是 0 展现，优先判断不再是“代码侧 robots/sitemap 全站阻断”，而是以下几类更高概率问题：

1. GSC 尚未重新发现或重新抓取新版 URL，特别是刚部署后存在数据延迟。
2. GSC 尚未在后台点击验证或请求抓取；HTML file、HTML tag、Google Analytics 代码侧已经上线。
3. sitemap 在 GSC 中未重新提交、旧 sitemap 仍残留，或 URL Inspection 还没触发重新抓取。
4. 新站/弱外链/内容同质化导致 Google 发现了 URL 但暂未收录或暂未产生查询曝光。

## 2. GSC 应提交的生产 sitemap

GSC 中只需要提交 2 个生产 sitemap 地址：

```txt
https://yayanews.cryptooptiontool.com/sitemap.xml
https://yayanews.cryptooptiontool.com/sitemap-news.xml
```

说明：

- `/sitemap.xml` 是 sitemap index，内部再引用多个 sitemap chunk，这是正常结构。
- `/sitemap-news.xml` 是 Google News sitemap。
- 不应单独提交 `/sitemap-chunk/...` 分片。
- 不应提交 `/sitemap-chunk/flash/0`；快讯详情当前规则是不进普通 sitemap。
- 如 GSC 里曾提交旧地址或错误地址，应删除后只保留上面 2 条。

## 11. GSC 0 展现排查路径

当前更建议按以下顺序排查，而不是继续优先改代码：

1. GSC 属性确认：Domain property / URL-prefix property / 验证方式。
2. Sitemap 提交状态：只保留 2 条生产 sitemap。
3. Pages 报告：看是否存在 `Discovered - currently not indexed`、`Crawled - currently not indexed`、`Duplicate without user-selected canonical`、`Alternate page with proper canonical tag`、`Blocked by robots.txt`、`Submitted URL marked noindex`。
4. URL Inspection：用代表性 URL 检查 Google 实际看到的 canonical、robots、抓取时间和索引状态。
5. 抓取等待：生产 SEO 修复刚生效后，GSC Performance 数据通常不会立刻更新。
6. 内容与站外发现：如果 URL 已抓取但不收录，需要继续提升原创度、主题差异、作者/来源可信度、内链与外链发现路径。
